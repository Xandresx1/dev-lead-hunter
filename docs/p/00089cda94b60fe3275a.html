Build TCF Practice Q&A on GitHub for FrenchKONNECT.com # Freelancer Project: Build a TCF French Practice Question Bank and Integrate It into FrenchKONNECT.com ## Project Overview I am looking for an experienced web scraper / Python developer to help build a comprehensive **TCF (Test de Connaissance du Français) practice question bank** for my website: **https://www.FrenchKONNECT.com** The project involves researching the content on **https://www.FreeTCF.com**, organizing relevant TCF question-and-answer material where extraction and reuse are authorized, developing original practice questions where necessary, and integrating the finished question bank into FrenchKONNECT.com. The ultimate goal is to create a well-organized, searchable, and interactive TCF practice platform for students preparing for the French language examination. ## Phase 1: Website Research and Content Collection Research the TCF-related educational content available on FreeTCF.com. Tasks: - Identify the available TCF practice sections and question categories. - Determine which questions, answers, explanations, and other materials can legally be extracted and reused. - Extract authorized content using appropriate tools such as Python, BeautifulSoup, Scrapy, Selenium, or Playwright. - Organize the collected information into a structured database. - Preserve relevant categories, answer choices, correct answers, explanations, and difficulty information where available. - Identify missing information, duplicate questions, incomplete answers, and formatting problems. ## Phase 2: Build an Original TCF Practice Question Bank Where content cannot legally be reproduced, develop original practice questions inspired by the relevant learning objectives and exam skills. The question bank should cover applicable TCF practice areas, including: - Listening comprehension - Reading comprehension - Grammar - Vocabulary - Language structures - Other relevant TCF preparation exercises For each question, include, where applicable: - Unique question ID - Category and skill - CEFR practice level (A1–C2, where appropriate) - Question text - Multiple-choice answers - Correct answer - Explanation of the correct answer - Difficulty level - Relevant tags Questions must be clearly written, accurate, and appropriate for French-language learners. Do not simply change a few words in copyrighted questions and present them as original. ## Phase 3: GitHub Repository Create and maintain a private GitHub repository, as agreed, to store and manage the project.
