Power Apps Form-to-Word Automation I'm looking for an experienced Microsoft Power Apps / Power Automate developer to build a simple, user-friendly electronic form that automatically generates a professionally formatted Microsoft Word document. The application is intended to streamline the preparation of standardised assessment reports in an administrative environment. Currently, staff manually complete Word templates. I want to replace this with an electronic form where users enter the required information into designated fields, select relevant options and click Generate to produce a completed, editable Word document. Required Features 1. Electronic Form Text fields for name, address, employee number, position, school, dates and reference numbers. Dropdown menus and checkboxes for notifications and assessment categories. Optional fields for relevant demographic information. Larger text boxes for Summary, Allegations, Witnesses, Intelligence, Physical Material and Conclusion/Recommendation. Ability to add multiple witnesses and document reference numbers. Conditional fields depending on selected options. 2. Word Document Generation Generate an editable Microsoft Word document (.docx) from the completed form. Automatically populate an existing professional Word template. Maintain consistent headings, tables, fonts, margins and page numbering. Automatically handle longer text without disrupting the formatting. Allow users to save, edit and print the generated document. 3. Two Document Types The application should generate either: Full Assessment Report, including all sections. Condensed Notification Record, for matters requiring only limited documentation. The appropriate fields should appear depending on the document type selected. Preferred Technology Microsoft Power Apps, Power Automate and Word templates, or an equivalent solution compatible with Microsoft 365 and SharePoint. The application should be straightforward to maintain, with the ability to update fields or Word templates without requiring extensive programming knowledge. Deliverables Fully functioning prototype using fictional information. User-friendly electronic form. Two professionally formatted Word document outputs. All editable source files and templates. Basic instructions for modifying and maintaining the application. Demonstration of the complete process from entering information to generating the document. Important This is initially a standalone proof of concept. No connection to government systems, confidential records or external databases is required. The developer must use fictional test information only. Please provide examples of similar projects, your recommended approach, anticipated completion time, any ongoing Microsoft licensing requirements and a fixed-price quote. Presupuesto: 30.0-250.0 AUD Skills: Data Entry, Branding, Sharepoint, Word, Microsoft Office, Automation
