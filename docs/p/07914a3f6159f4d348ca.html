Build Zapier Textable SMS Automation Project Overview I'm looking for an experienced Zapier/API freelancer to build and test an automated SMS drip campaign workflow connecting Google Drive, Zapier, and Textable. I will manually upload a CSV file containing approximately 500 new, opted-in phone numbers to a designated Google Drive folder each day. Your job is to build the automation once. After setup, the workflow must run automatically whenever I upload a new CSV, without any further manual intervention. Required Automation 1. Zapier detects a new CSV uploaded to the designated Google Drive folder. 2. Zapier reads the CSV and extracts the phone numbers. 3. Zapier creates or identifies the corresponding contacts in Textable using its API. 4. Zapier enrolls those contacts into one existing, reusable Textable drip campaign. 5. Textable sends the two predefined SMS messages: - Message 1: Immediately upon enrollment. - Message 2: Exactly 14 days (336 hours) after Message 1. Both messages use the same fixed text for every contact. No personalization or daily message changes are required. The automation must reuse the same Textable drip campaign for every CSV. It must not create a new campaign for each upload. The workflow must prevent accidental duplicate enrollments or messages, handle failed API requests appropriately, and support approximately 500 contacts per uploaded CSV. Textable API API documentation: https://textbetter-txb.textable.app/docs/html The documentation includes endpoints for creating contacts, retrieving existing drip campaigns, and enrolling contacts into a campaign. The freelancer is responsible for the complete technical setup, including API authentication, required identifiers, contact mapping, Zapier configuration, and testing. I do not want to perform any technical setup myself. Zapier is required. Please do not propose replacing it with another automation platform. Deliverable: A working test-contact proof of concept and a brief written feasibility assessment identifying any technical blockers.
