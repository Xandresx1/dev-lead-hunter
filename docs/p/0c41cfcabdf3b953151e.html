Nula Move Platform Implementation Support Nula Move — Developer Specification / Master Plan We need implementation support for the Nula Move mobility platform. Please review and implement the following open items: 1. Home screen & search - Searching from the home screen must go directly into the ride/booking flow without a separate intermediate step. - Map should take approx. 95% of the screen in this flow. - Goal: GPS automatically fills the pickup location, customer only enters destination, and lands immediately on a map-centered view. 2. Booking fields - After location permission is granted, the pickup location should autofill via GPS. - Pickup location and destination must be side by side, not stacked. - Add a “+” button between the fields to add a stopover. - Add a swap button next to the fields so pickup and destination can be switched. - Add a map icon in the top right. 3. Booking flow without login - Even without login, visitors should be able to enter pickup and destination and compare price and distance across offers. - Show nearby vehicles on the map. - Only when clicking “Book now”, ask the user to register with phone number or email. 4. Navigation next to the logo - The main navigation should be placed next to the logo. - Items: Ride, Rent, Rent Out. - Each item must open only its own section. - “Rent Out” is for vehicle owners only. 5. Bug fix - Clicking “Rent Out” currently leads to the wrong page. - It must lead to the vehicle owner registration page. 6. Vehicle rental section - Show the message for vehicle owners: “Sign up as a vehicle owner, rent out your vehicle, and earn money. Register now, upload your vehicle — Nula Move takes care of the rest.” 7. Compare vehicles — self-drive - Merge under Ride → Compare Vehicles — Self-Drive: - All vehicles - Self-drive - Cars with driver - Scooters - Public transit - Combined routes 8. Ride flow - Add an “Activity” button during the ride at the top center. - Add a swipe bar at the bottom to end the ride. - After confirmation, show a polite closing message. 9. Payment flow - Stripe SetupIntent for card saving. - PaymentIntent with manual capture at booking. - Show a friendly error if authorization fails. - Show arrival notification when the vehicle is within 250 m. 10. Footer navigation - Products: Ride-hailing, scooters, e-bikes, self-drive. - Safety, Support, Earn. - Legal links: Terms, Privacy Policy, FAQ. - About Us should be small and placed at the bottom. 11. Privacy - Shared location must only be visible in the Nula Move admin dashboard. Please implement these items in a mobile-first way and keep the app reliable for users with weaker phones or connections. Presupuesto: 750.0-1500.0 USD Skills: Mobile App Development, User Interface / IA, Mobile App Testing, Mobile Development, API Development, Payment Processing
