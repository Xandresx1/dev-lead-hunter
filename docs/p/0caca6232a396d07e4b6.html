Agent IA Recherche Pièces Powersport Je veux mettre en place une première version d’un agent IA qui aidera exclusivement mon équipe à trouver, en quelques secondes, la bonne pièce powersport pour nos clients. Fonctionnalités attendues • Point d’entrée simple : mon équipe pourra saisir la marque, le modèle et l’année du véhicule, un numéro de pièce ou de série, ou encore joindre une photo ou une courte description du besoin. • Recherche multi-sources : l’agent devra parcourir simultanément – nos catalogues PDF fournisseurs, – les sites web de ces mêmes fournisseurs, – notre système interne d’inventaire et de ventes. • Résultats clairs : il doit retourner immédiatement les correspondances possibles, avec référence catalogue, disponibilité et prix lorsqu’ils sont accessibles. • Interface interne : une page ou application web simple, utilisable sur poste de travail et tablette, suffira pour cette première version. • Mise à jour facilitée : je souhaite pouvoir ajouter de nouveaux catalogues PDF ou modifier les sources web sans développement lourd. Livrables 1. Prototype fonctionnel prêt à être testé par mon équipe. 2. Code source, documentation d’installation et d’usage. 3. Guide pour intégrer de nouveaux catalogues PDF et gérer l’accès aux sites fournisseurs. Contraintes et préférences techniques – Solution compatible Windows et navigateur Chrome. – Technologies ouvertes (Python, Node.js, LangChain, OpenAI API ou équivalent) privilégiées tant qu’elles restent pérennes. – Traitement multilingue français/anglais apprécié. – Respect de la confidentialité des données internes. Cette version interne est la première étape ; si tout se passe bien, j’envisage ensuite l’ajout de la vérification automatique des stocks fournisseurs puis, ultérieurement, l’ouverture d’une interface de commande directe pour nos clients. Presupuesto: 250.0-750.0 USD Skills: Python, Graphic Design, Data Entry, Web Scraping, Web Search, Node.js
