disener site web -- 2 i web inmobiliaria de WordPress ya tiene IDX Broker asociado a la cuenta, pero la configuración por defecto no ofrece la experiencia de usuario ni el flujo de datos que necesito. El trabajo es tomar la instalación existente de IDX Broker y convertirla en un motor generador de leads completamente marcado que hable perfectamente con mi CRM y muestre los anuncios en un diseño que se sienta nativo del resto del sitio. Objetivos clave • Filtros de búsqueda personalizados – los compradores deben poder reducir los resultados según los criterios específicos que usamos localmente (zona escolar, cuotas de la comunidad, límite de alquiler y algunos otros que proporcionaré). Estos filtros deben estar dentro del widget de búsqueda de IDX Broker y mantener URLs optimizadas para SEO. • Integración con CRM: cada nuevo lead, búsqueda guardada y solicitud de visualización generada por IDX Broker debe enviarse instantáneamente a mi CRM mediante API o webhook (proporcionaré el endpoint y el mapa de campos). No se permiten exportaciones manuales. • Diseño único de la propiedad – las páginas individuales de los anuncios deben reflejar el estilo de mi tema, con imágenes heroicas, datos clave fijos y secciones de contenido reorganizadas. Se esperan ediciones ligeras en CSS/HTML/PHP para que el diseño se sienta hecho a mano en lugar de un iframe drop-in. Entregables 1. Cuenta IDX Broker configurada conectada al sitio WordPress en activo. 2. Añadió y probó parámetros de búsqueda personalizados reflejados en filtros frontales y cadenas de URL. 3. API o enlace webhook que envía datos potenciales al CRM, verificado con envíos de muestras. 4. Plantilla renovada de un solo anuncio que coincide con la tipografía y paleta de colores de mi tema, y responde en móvil. 5. Breve documento de entrega que indique dónde se cambiaron el código o los ajustes para poder mantener la configuración. Criterios de aceptación: aparecen filtros que devolven resultados correctos; nuevos contactos aparecen en el CRM en menos de 60 segundos; las páginas de los anuncios superan la prueba Google Móvil-Friendly y no presentan ningún diseño roto. Administrador de WordPress, panel de control de IDX Broker y credenciales CRM se proporcionarán una vez que acordemos el alcance. Habilidades requeridas PHP WordPress CSS CRM MySQL HTML Desarrollo web Integración API Presupuesto: 250.0-750.0 EUR Skills: PHP, SEO, WordPress, CSS, CRM, MySQL
