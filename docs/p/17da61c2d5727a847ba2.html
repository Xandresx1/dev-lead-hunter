Android Wake-Word Recorder I need a small Android application that constantly listens for a single wake word, then—without any extra taps—begins recording audio straight away. As soon as the recording ends it should push the file to a cloud location I can configure (Google Drive, S3, or similar). Feel free to leverage Porcupine, Snowboy, TensorFlow Lite, or another lightweight engine, provided it performs reliably on common Android phones and tablets.
