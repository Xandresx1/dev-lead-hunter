Energy Freelance Marketplace Website I am building an online marketplace that mirrors the core flow of Freelancer.com but is focused exclusively on power-engineering work worldwide. Energy companies will create employer accounts and publish project “packages” in three initial categories—substations, overhead transmission lines, and renewable-energy installations. Both individual specialists and full engineering firms will be able to register as bidders, browse open packages, and submit competing proposals. Every job post must capture four key fields: the project description, all relevant technical files, the work location (map integration is fine), and the level of experience required. Bidders need personal or corporate profiles, a secure file-exchange space for clarifications, and a straightforward way to place, edit, or withdraw their bids before the employer’s closing date. Core workflow and features • Role-based registration: employer, specialist, or firm • Project creation wizard with category tagging and file upload • Search and filter by discipline, voltage class, country, or deadline • Bid submission thread with messaging and notification system • Award, milestone, and basic dispute tracking tools • Commission or escrow-style payment gateway • Admin dashboard for user, project, and fee management • Fully responsive design so field engineers can work from tablets or phones Deliverables for acceptance 1. Complete source code and database schema (preferably Laravel + Vue, React, or an equally modern stack). 2. Deployed test site on a cloud instance with SSL. 3. Admin guide covering user onboarding, category management, and payment settings. With these pieces in place, the platform will let energy companies quickly publish specialist packages while giving both individual experts and engineering firms a transparent space to compete for global power-sector work. Presupuesto: 750.0-1500.0 USD Skills: PHP, Website Design, WordPress, HTML, Laravel, React.js
