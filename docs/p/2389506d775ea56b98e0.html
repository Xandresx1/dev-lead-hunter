AI Image-to-Text Q&A Assistant I’m building an application that lets a user drop any image of a document, worksheet, or mixed-content photo into the browser and immediately receive (1) clean, editable text extracted from the picture, (2) automatic detection of any questions it contains, and (3) clear, step-by-step answers plus the option to keep chatting about that content. In practice this means combining a solid OCR pipeline with vision-language reasoning from a large language model so the system actually “understands” tables, diagrams, and context, not just the printed words. I already have the general product flow sketched out; what I need from you is the full technical implementation—image ingestion, vision model, text post-processing, and conversational layer—wrapped in a simple web interface that can later be embedded in mobile or desktop wrappers. Core expectations • High-accuracy OCR on varied image quality (scanned PDFs, phone photos, multi-column pages). • Vision-language model that can locate questions visually and return an explained answer, not just a short fact. • Follow-up chat powered by the same context so the user can ask “why?” or “show me the steps again” without re-uploading. • Clean, well-commented code and a short README describing model choices, libraries, and how to redeploy. Preferred toolset: Python, PyTorch or TensorFlow for any fine-tuning, Tesseract/EasyOCR or equivalent for baseline extraction, OpenAI GPT-4 or a comparable multimodal LLM via Hugging Face, plus a lightweight Flask/FastAPI backend and a React or simple HTML/JS front end—open to suggestions if you have a better stack. Deliverables 1. Source code repository with build/run instructions 2. Deployed demo (can be on Heroku, Vercel, or similar) 3. Brief model architecture and evaluation notes 4. Quick video or screenshots showing the workflow from upload to answer Once the prototype meets accuracy and latency targets we can discuss ongoing refinement, dataset expansion, and mobile packaging. If you have prior work in multimodal AI, OCR, or educational Q&A systems, I’d love to see it alongside your proposal. Presupuesto: 250.0-750.0 USD Skills: Python, HTML, OCR, Flask, Tensorflow, Pytorch
