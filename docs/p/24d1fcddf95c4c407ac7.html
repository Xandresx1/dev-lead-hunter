Offline PHP POS for Retail I need a cloud-based point-of-sale system written entirely in PHP that serves a retail shop / supermarket environment. At the counter it should feel as fast as a desktop register, but all data must ultimately live in the cloud so I can monitor sales and inventory from anywhere. Core sales flow • Scan a barcode, pull the product record instantly, print a receipt on a standard thermal printer without extra clicks. • If the internet drops, the cashier must still complete the sale; the system stores the ticket locally and pushes it to the server automatically once the connection is restored. Stock levels are then updated during that sync cycle. Inventory & alerts Item counts need to decrement in real time, trigger low-stock warnings, and appear in an admin dashboard where I can adjust quantities, import new products, or download a CSV. Customer engagement Each shopper can be identified by phone, loyalty card, or barcode on the receipt. Their purchases accumulate points that the cashier can redeem on the next visit. Technology expectations – PHP for all server-side logic (a modern framework such as Laravel is welcome but not mandatory). – MySQL or MariaDB in the cloud; a lightweight local store (SQLite or IndexedDB) for offline tickets is fine as long as syncing is robust and handles conflicts. – Front end should be responsive so the same codebase runs on a 10" tablet at the till and on a desktop in the back office. – Clear separation between cashier interface and admin interface. Deliverables 1. Full commented source code and database schema 2. Installation guide for both local store and cloud host 3. Brief document explaining offline-to-online sync logic 4. Test data set and instructions so I can simulate a disconnect, run sales, reconnect, and see stock update correctly Once installed successfully I will run live transactions for a week; final payment releases after the system syncs every ticket and no data is lost. Presupuesto: 20.0-250.0 GBP Skills: PHP, Cloud Computing, Software Architecture, MySQL, HTML, Laravel
