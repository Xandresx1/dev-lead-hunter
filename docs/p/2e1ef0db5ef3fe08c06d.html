Multiagente Redes Sociales Integrado Necesito desarrollar un multiagente capaz de atender de forma automática los mensajes que llegan por WhatsApp, Instagram y Facebook Messenger. El objetivo principal es que el sistema responda de manera natural y coherente a: • Preguntas frecuentes sobre nuestros productos o servicios • Consultas relacionadas con ventas y pedidos • Solicitudes de soporte y resolución de problemas Cuando el bot no pueda resolver una consulta, deberá transferir la conversación a una persona de mi equipo sin pérdida de contexto. Busco una solución que incluya: – Integración estable con las API oficiales de los tres canales mencionados. – Motor de procesamiento de lenguaje que permita respuestas personalizadas y consistentes. – Lógica de enrutamiento inteligente para identificar cuándo derivar al equipo humano. – Panel o dashboard básico para que podamos supervisar conversaciones, añadir respuestas y actualizar flujos. Entrego la documentación de marca y las FAQ existentes; tú te encargas de configurar, entrenar y probar el modelo para que quede listo para producción. Valoraré experiencia previa con bots multicanal, WhatsApp Business API, Meta Graph API y buenas prácticas de hand-off a agentes humanos.
