WordPress Event Registration Integration I’m setting up an event on my WordPress site and need the full registration flow put in place. Scope of work – Build or configure the WordPress form and map it to Stripe Checkout. WordPress, Brevo & Stripe – flow process for events that is repeatable in the future and can be moved to a new website in the near future 1. Project Objective Build one complete, working event registration, payment, with email communication system using the existing WordPress website, Brevo account, and Stripe account integration. The system must support a repeatable setup to be used for independent events while only changing the event details each time. The client will provide all email content and event-specific information. The freelancer is responsible for building the flow with technical configuration, integration, automation logic, basic testing, and written documentation to sign off. The automation is to come from the existing aspects of Registration form, Brevo and Stripe Basic Concept of flow Brevo Flow = Registration form on wordpress event page>submit will add to an event list and main list>sends email of registration to client and admin >takes client to stripe payment link> On payment > adds client to secondary list of paid and if they do not pay to an Unpaid relevant to the event name and list 2 Days prior to the event email goes to unpaid list as a reminder for payment > if they pay the persons registration gets added to the paid list 8 hours prior to the event > email with event details gets sent to paid list Anyone registering and pays after this window gets added to the main list and the paid list and gets the event details via email People can register and pay up to the end of the event Email to be sent post event manual timing for the recordings. – Connect the successful payment webhook to Brevo so the confirmation email fires instantly. – Style the email template inside Brevo to match my existing brand colors and add a calendar-add link – Test the entire flow end-to-end in both Stripe test mode and live mode, fixing any field mapping or formatting issues you notice. – Hand over clear instructions (or a short Loom) showing me how to update prices, dates, or email copy in the future. Acceptance criteria 1. A new user can register, pay, and receive the confirmation email without manual intervention. 2. All captured data appears in both WordPress form entries and the Brevo contact record. 3. No duplicate or missing records after multiple test submissions. 4. Visual styling matches the current site on desktop and mobile. Webpage is ready, the email content will be provided. Please quote based on your expectation of payment from this listing. If something needs to be added can be discussed. Thanks for your attention to this !
