Tienda web para renders 3D Necesito desarrollar una página web que me permita vender mis servicios de visualización 3D de forma completamente automática. El flujo ideal es el siguiente: 1. Catálogo y compra • El cliente elige el tipo de render entre las opciones que yo defina. • Antes de pagar debe completar un formulario donde indique: – Tipo de espacio y tamaño aproximado. – Estilo visual y materiales deseados. – Cantidad de imágenes y vistas que necesita. • El pago se realiza en un solo paso, pago completo al hacer el pedido, mediante pasarela segura (tarjeta, PayPal u otra que recomiendes). 2. Subida de planos • Tras el pago, el usuario debe poder adjuntar sus planos (PDF, DWG, JPG, etc.) desde su cuenta. • Los archivos deben almacenarse de forma segura y ser accesibles solo para el administrador. 3. Entrega del render • Cuando finalice el proyecto podré subir los renders finales al pedido. • El cliente recibirá una notificación y podrá descargar los archivos de alta resolución desde su panel privado. 4. Panel de administración • Dashboard para ver, filtrar y cambiar el estado de los pedidos. • Área para subir renders finales y generar notificaciones automáticas por correo electrónico. 5. Tecnología y estructura • Estoy abierto a WordPress + WooCommerce, Shopify o una solución custom en React/Laravel; priorizo facilidad de gestión y escalabilidad. • Diseño responsive, carga rápida y optimizada para SEO básico. • Idioma principal: español, con la posibilidad de añadir inglés en el futuro. Acepto sugerencias adicionales siempre que no compliquen el flujo principal; por ejemplo, más adelante podríamos integrar un módulo para crear planos sencillos en línea, pero ahora prefiero concentrarme en la compra, la subida de archivos y la descarga de renders. Entregar: • Sitio web funcional en hosting propio o servidor que sugieras. • Documentación breve para actualizar precios y gestionar pedidos. • Soporte breve post-lanzamiento para resolver ajustes menores. Si ya has trabajado con ecommerce de servicios creativos o manejas integraciones de subida/descarga de archivos pesados, quiero saber cómo lo implementaste y qué plugins o APIs utilizaste. Presupuesto: 250.0-750.0 EUR Skills: PHP, Website Design, WordPress, 3D Rendering, 3D Modelling, Laravel
