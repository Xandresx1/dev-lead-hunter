FiveM Enhanced MLO/YMAP Developer - Conversion, Conflict Resolution, Consolidation, Optimize and In-Game Testing Fixed total budget: USD 500-700 for the agreed full scope, not per group. We need an experienced FiveM mapping developer to prepare our existing YMAPs and associated assets for FiveM Enhanced. This project covers existing map files and their required models, textures, collisions, archetypes, occlusion and LOD data. It does not involve general framework development, gameplay systems or creating new interiors from scratch. You must already have a working GTA V Enhanced installation, FiveM Enhanced test environment, CodeWalker and the required conversion tools before accepting. Required work 1. Convert assets for FiveM Enhanced - Convert applicable Legacy models and textures using FiveM Alchemist or an appropriate verified workflow. - Preserve the required YMAP, YTYP, collision and other supporting map data. - Verify that the resulting assets load correctly in FiveM Enhanced. - Report conversion failures or unavailable source files promptly. Conversion logs or a folder named stream_enhanced alone do not establish completion. 2. Merge and organize map resources Consolidate the supplied maps and assets into: - x6-businessmaps - x6-shadowmaps - x6-governmentmaps - x6-housingmaps - x6-jobmaps - x6-leisuremaps - x6-worldmaps - x6-mapdata for agreed shared mapdata and compatibility files. The target is one working map resource per category, with a correct top-level manifest, required registrations and an organized streaming structure. Identify any technical or asset-protection restriction before proceeding. Do not simply move unchanged individual resource folders under a category folder and describe them as merged. 3. Resolve map and asset conflicts Identify and resolve: - Duplicate filenames with different contents. - Conflicting map definitions and archetypes. - Overlapping placements and map edits. - Collision, occlusion, LOD and streaming conflicts. - Conflicts between category groups and shared mapdata. Removing duplicate filenames is not necessarily conflict resolution. Preserve the required changes from each affected map. Do not select a conflicting version solely by alphabetical order, load order or file size. Document the resolution and validate it in game. Do not remove maps, replace businesses or choose between overlapping alternatives without our approval. 4. Repair and optimize Within the agreed asset inventory: - Fix missing models, props and textures. - Address texture loss, flickering, incorrect collisions and visibility issues. - Review and repair LODs, draw distances, map bounds and lighting where needed. - Optimize textures and models where justified, preserving acceptable visual quality. - Clean unnecessary files from the delivery. - Verify compatibility when all supplied groups run together.
