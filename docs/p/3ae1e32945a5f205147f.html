Project Overview We want to develop an affordable, AI-powered administration system for our abattoir and meat sales business. The main objective is to automate invoicing, stock control, payment tracking and financial reporting while keeping the system simple enough for everyday use. The system must integrate WhatsApp communication with a central database that can be accessed and managed from a Windows laptop. 2. Stock and Inventory Management The system must include a stock management function directly linked to invoicing. Required functionality: * Stock will be entered manually using a laptop. * Each meat product must have its own stock balance, measured primarily in kilograms. * Products include rump, T-bone, biltong cuts, mince, boerewors, stew, shins and other meat products. * The user must be able to add new stock, adjust quantities and correct errors. * The system must automatically deduct the quantity sold from stock when an invoice is finalized. * Stock must not be deducted twice if an invoice is edited or processed again. * Cancelled or corrected invoices must update stock appropriately. * The system should display current stock balances and identify products running low. * Every stock movement must be recorded for traceability. Example: * Starting rump stock: 50 kg * Customer purchases: 8 kg * Invoice generated and finalized: 8 kg * Remaining rump stock: 42 kg The system must automatically update the available rump stock to 42 kg. 3. Automated Invoice Generation The system must generate professional PDF invoices for meat sales.
