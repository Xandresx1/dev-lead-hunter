Automate Legal Documents on WordPress Project Brief: Automated Legal Document Production System Project Overview We are looking for an experienced developer to build a simple, cost-effective automated legal document production system for an existing law firm. Important: We already have an existing WordPress website. We do NOT need a new website built. The project involves adding legal services and fixed-fee document packages to the existing WordPress website, allowing clients to purchase services, complete online questionnaires, upload supporting documents and receive professionally prepared legal documents following solicitor approval. We need Stripe integrated into the existing website so clients can select a service, make payment and complete the required onboarding process. We have a strict project budget and are looking for someone who can deliver a practical, reliable solution without unnecessary complexity or expensive custom development. Required Workflow Existing WordPress website: Add legal services and fixed-fee document packages to the existing website, including service descriptions, pricing and inclusions. Online purchasing: Integrate Stripe into the existing WordPress website so clients can purchase their selected legal service. Questionnaire: Following service selection, clients complete an online questionnaire and upload relevant supporting documents. CRM integration and conflict checks: Connect to the firm's existing SILQ CRM to identify existing clients, check relevant parties for potential conflicts and flag potential matches for solicitor review. New client details and approved matters must be saved in SILQ. Conflicts must not be automatically cleared by AI. Engagement and payment: Client receives the relevant costs agreement, accepts the terms and completes payment through Stripe. Matter acceptance and payment must be verified before document production begins. Automation: n8n triggers the workflow following verified payment and the required matter acceptance checks. AI processing: OpenAI extracts and structures client information, while Claude prepares documents using approved legal templates and instructions. Document generation: Generate professionally formatted, branded and fully editable Microsoft Word (.docx) and PDF documents. Solicitor review: Provide a simple, secure interface where solicitors can review documents, download Word/PDF versions, manually edit Word documents and upload revised versions. AI amendments: Solicitors can request AI amendments or make their own manual changes. All document versions must be retained. Final approval: A solicitor must explicitly approve the final document before it can be released. Client delivery: Automatically deliver the approved document securely by email. Feedback: Send an automated client feedback or review request. Required Technology We would prefer to use existing services and avoid unnecessary custom software development.
