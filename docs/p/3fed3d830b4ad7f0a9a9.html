Asistente FAQ para WhatsApp Quiero poner en marcha un asistente virtual dentro de mi número de WhatsApp Business que se encargue exclusivamente de responder las preguntas frecuentes de mis clientes. El interés principal es que cualquier persona pueda consultar, en el mismo chat, qué productos tengo, su precio y si hay stock disponible en ese momento. Yo facilitaré un archivo actualizado con todo el catálogo: nombres, descripciones breves, precios y unidades disponibles. El bot tiene que leer esa fuente, interpretarla y contestar de forma clara cuando el usuario pregunte, por ejemplo, “¿Tienes el modelo X?” o “¿Cuánto cuesta el producto Y?”. Siempre debe basarse en la información que encuentre en el archivo y no inventar datos si algo no está listado. Además de entregar el bot funcionando dentro de WhatsApp (puede ser mediante la API oficial, Twilio, Meta Cloud o la solución que domines), necesito que me expliques cómo sustituir el archivo cada vez que renueve el inventario para que las respuestas sigan actualizadas. Una breve guía paso a paso es suficiente. Entrego: • Archivo CSV/Excel con el catálogo. Espero: • Chatbot activo en mi línea de WhatsApp Business. • Integración lista para refrescar datos con el nuevo archivo. • Instrucciones sencillas para hacer ese reemplazo. Si ya tienes experiencias previas montando bots con la API de WhatsApp o librerías como Python-WhatsApp, Node, Dialogflow, etc., cuéntamelo en tu propuesta y elige la que veas más ágil.
