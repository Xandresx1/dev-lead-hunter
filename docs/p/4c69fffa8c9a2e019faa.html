Raspberry Pi Locker System Gym Raspberry Pi 4 Smart Locker System – CAN Bus, RFID and Automatic Lock Initialization 1. Project Overview We are looking for an experienced developer to build a smart locker management system for a small fitness studio, using a Raspberry Pi 4, electronic locks, CAN bus communication, and RFID cards. Our existing electronic locks communicate via CAN bus and an API. We have identified the following GitHub repository as a starting point: GitHub repository: https://github.com/sigar-nxp/CAN We want to reuse existing functionality wherever possible. Important: Before starting the complete development, we want to verify that the developer can successfully initialize new locks and assign them unique IDs. This is the most critical technical requirement and the first, separately paid project phase. 2. Phase 1 – Proof of Concept: Automatic Lock Initialization The first assignment is limited to verifying and demonstrating that new locks can be initialized and uniquely addressed. Our locks are delivered with the default software CAN ID 1. According to our current understanding, they do not have a separate hardware identification number. We need to establish whether it is technically possible to connect multiple locks, identify each new lock individually, and assign a unique software ID to each one. The developer must: * Review the existing GitHub repository and relevant documentation. * Analyze the CAN bus protocol and available API commands. * Determine how locks with the default ID 1 can be distinguished from one another. * Investigate whether the hardware supports a commissioning, learning, or address-assignment procedure. * Implement and test a proof of concept using the actual hardware, subject to hardware availability. * Demonstrate that multiple locks can receive different IDs and remain individually addressable. * Document any hardware, firmware, or protocol limitations. Expected result: A working demonstration of the initialization procedure, or a clear technical report explaining why it is not possible with the existing hardware and what changes would be required. We do not want to invest time or money in the full application until this fundamental requirement has been verified. Please provide a fixed-price quote for Phase 1 only. 3.
