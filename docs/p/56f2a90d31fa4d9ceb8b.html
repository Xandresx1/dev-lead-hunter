Website Pencatatan Bisnis Online Saya membutuhkan sebuah website responsif yang dapat diakses di semua perangkat untuk keperluan pencatatan bisnis. Fokus utamanya adalah mencatat dan menampilkan data penjualan, pelanggan, serta pembayaran dalam satu sistem terpadu. Ruang lingkup pekerjaan: • Rancang antarmuka bersih dan mudah digunakan, baik di desktop maupun seluler. • Buat modul input data penjualan yang terhubung langsung dengan database. • Sertakan menu khusus pelanggan untuk menambah, mengedit, dan mengarsipkan informasi mereka. • Bangun fitur pencatatan pembayaran berikut status pelunasan agar saya dapat memantau arus kas dengan cepat. • Tampilkan ringkasan data dalam dashboard—grafik sederhana atau tabel dinamis—agar tren penjualan mudah dipahami. • Pastikan ada opsi ekspor (CSV atau Excel) untuk laporan penjualan dan pembayaran. Persyaratan teknis: • Teknologi web modern (contoh: React, Vue, atau plain PHP + MySQL) dipersilakan; silakan pilih stack yang paling efisien bagi Anda. • Situs harus responsif tanpa memerlukan aplikasi terpisah, sehingga kompatibel di Android, iOS, dan desktop. • Sertakan dokumentasi singkat tentang cara menginstal dan memelihara sistem. Hasil akhir yang saya harapkan adalah website siap pakai lengkap dengan database terpasang, akun admin pertama, dan panduan singkat pengguna.
