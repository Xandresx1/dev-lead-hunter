App de Streaming en React Native para Amazon Vega OS (Kepler SDK / Fire TV) Necesito desarrollar una aplicación completa en React Native para Amazon Vega OS (usando Kepler SDK) orientada a Fire TV. La app transmitirá tanto canales de TV en vivo como contenido bajo demanda (VOD) conectándose a nuestra plataforma actual, respetando las guías de diseño de Fire TV y la navegación fluida mediante control remoto (D-pad). El servicio ya está activo y en producción en Roku y Android TV, por lo que entregaré capturas/videos de referencia de nuestra interfaz actual y la documentación de nuestra API para agilizar el desarrollo. Experiencia principal y funcionalidades Acceso y gestión de cuentas: Vinculación del televisor mediante código en pantalla, soporte para múltiples perfiles con bloqueo por PIN, favoritos y sincronización de progreso (Continuar viendo). Secciones de contenido: Inicio (Home), TV en vivo con guía EPG, Películas, Series, Sección Infantil, Eventos de Pago por Evento (PPV), Buscador y Perfil. Reproducción multimedia: Reproducción por URL directa en HLS, MP4 y MKV (no DRM). El reproductor debe soportar cambio de pistas de audio (varios archivos MKV incluyen 2 o 3 pistas de audio), subtítulos, reproducción automática del siguiente episodio, reanudar desde el punto exacto donde se dejó y reporte de errores de reproducción. Alcance del trabajo y arquitectura Configurar el proyecto desde cero en React Native con Kepler SDK e integrar sus componentes nativos de reproducción multimedia (W3C Media / GStreamer), optimizando el rendimiento y uso de memoria RAM (1 GB RAM en dispositivos como Fire TV Stick 4K Select). Conectar la app a nuestra API REST ya en producción (PHP 8.3 + MariaDB) que entrega respuestas JSON por HTTPS y gestiona cuentas, vinculación, perfiles, favoritos y progreso. Los flujos de TV en vivo y VOD provienen de servidores de streaming externos independientes. La app de Vega OS debe integrarse a nuestra API y servidores actuales tal como están, sin modificar el backend. Una vez iniciado el proyecto, entregaré todos los recursos gráficos (artwork), credenciales de prueba, flujos de ejemplo y documentación de la API. Entregables Código fuente completo en React Native alojado en un repositorio Git. Compilación lista para producción e instalación de prueba en Fire TV Vega OS (paquete .vpkg). Instrucciones claras de compilación y despliegue (build & deployment). Guía técnica breve explicando la estructura del proyecto y cómo realizar futuros ajustes o añadir categorías. Soporte/acompañamiento durante el proceso de revisión y publicación en la Amazon Appstore. Criterios de aceptación La app se instala, abre y navega sin bloqueos en hardware físico con Vega OS (Fire TV Stick 4K Select).
