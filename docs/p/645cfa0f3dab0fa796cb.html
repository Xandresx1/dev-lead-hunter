Driver Bidding Taxi Platform I need a streamlined taxi-booking backend focused solely on drivers and dispatch. The system breaks down into two key components: 1. Driver mobile app • Receives ride requests that arrive already priced in several preset tiers. • Lets the driver tap one of those price options to submit a bid—fast, with no manual typing. • Shows real-time request details, navigation links, status updates (en-route, picked-up, completed) and basic earnings history. • Push notifications must alert drivers the moment a new request appears or when their bid wins. 2. Web-based admin panel • Imports ride requests automatically from our existing system (API or scheduled file drop—whichever you advise) and routes them to available drivers. • Provides live tracking of active trips, bid activity, driver availability, and basic reporting. • Offers CRUD control over driver accounts, preset price tiers, and system settings. Core acceptance criteria • Clean, responsive UI on both app and panel. • Seamless import of external ride data with no manual intervention. • Bid flow limited to the predefined price choices; no free-form pricing. • Stable build ready for production, tested on at least one Android device (iOS optional but welcome). • Clear hand-over: source code, build instructions, and a brief admin guide. Feel free to recommend the tech stack you believe will ship a reliable cross-platform driver app and a secure admin dashboard within a reasonable timeline.
