Full-Stack Developer Needed –Membership Portal & Dashboard Integration (Laravel) We are seeking an experienced full-stack developer to design and develop a complete, secure, database-driven membership portal and personalized member dashboard for our website. An existing membership database is available, but the member dashboard and portal must be developed from scratch in Laravel. Project Requirements: 1. Dashboard Design & Development: Design and build a modern, professional, mobile-responsive member dashboard consistent with AAPSCM® branding. 2. Membership Registration: Develop a secure online registration, account activation, and login system for existing members. 3. Member Identity Verification: Integrate the existing membership database to authenticate members using their membership IDs or certificate IDs, with appropriate identity verification. 4. Account & Password Management: Allow verified members to create personal accounts with secure passwords, mandatory password changes every 30 days, and password recovery functionality. 5. Automated Profile Population: Automatically retrieve and display each member's personal information, professional details, membership category, status, and expiration dates from the existing database. 6. Certification Integration: Connect certification records to individual member accounts and automatically display earned certifications, certificate IDs, issue dates, expiration dates, and digital credentials. 7. Dashboard Modules: Develop functional sections for Dashboard Overview, Membership, My Profile, Certifications, Orders, Exams, Training & Learning, Events & Webinars, Chapters & Communities, Resources & Publications, and Account Settings. 8. Administrative Management: Develop an administrative interface for managing member accounts, certifications, membership status, resources, and access permissions. 9. Database Integration & Automation: Integrate existing membership records with the new portal and enable automatic synchronization of relevant member information. 10. Security & Access Control: Implement secure authentication, role-based permissions, member-specific data protection, and appropriate cybersecurity safeguards. 11. Testing & Deployment: Conduct complete system testing, resolve technical issues, deploy the portal, and provide technical documentation. Required Expertise: Full-stack web development, PHP/Laravel or compatible technologies, MySQL, API integration, UI/UX design, database management, and secure membership management systems. Bidders must provide: Examples of similar completed projects, proposed development approach, estimated completion timeline, and a fixed-price quotation.
