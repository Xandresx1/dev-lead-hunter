WooCommerce Auto Parts Inventory Integration We need an experienced WooCommerce developer to create an independent inventory integration and parts-search solution for ABC Auto Wrecking in Tucson, Arizona. Our current website is https://abcautowreckingaz.com. It uses WordPress/WooCommerce and URG’s IIS inventory plugin. We want to replace our dependence on URG while retaining our existing website where practical. We use Checkmate for yard inventory management. Buddy Automotive Innovations currently participates in transferring our inventory to URG. Direct access to that feed and website interchange licensing still need to be confirmed. Project requirements: • Automatically import and update a large inventory catalog, including prices, descriptions, photos, stock numbers, mileage, and availability. • Reliably remove or mark sold parts unavailable. • Provide vehicle and part searches using properly licensed interchange/fitment data. • Support our freight and small-package shipping rules, terminal pickup, and residential surcharges. • Maintain reliable, fast cart and checkout functionality. • Connect inventory to our existing Google Merchant Center and Google Ads accounts, preserving product IDs and URLs where possible. • Preserve order history and existing payment and ShipStation integrations. • Develop and test on a staging site before making changes to the live store. • Include monitoring for failed inventory updates and documentation another developer can follow. Ownership and support: ABC must own the custom code and receive complete, readable source code under a written ownership agreement. Hosting and code repository accounts must be controlled by ABC. Identify all third-party software, licenses, and recurring charges in your proposal. We also need ongoing maintenance and clearly stated emergency-support availability, including evenings and weekends. Please provide examples of inventory integrations and large WooCommerce stores you personally developed. Experience with Checkmate, Buddy, Hollander interchange, or auto recyclers is strongly preferred. We want to begin with a paid technical assessment to confirm data access, licensing requirements, architecture, timeline, and a milestone-based development quote. Please explain which existing plugins you would use and which components require custom development.
