QA Tester for Secure AI Knowledge MVP Title: QA Tester for AI Q&A and Document Metadata MVP (RAG / LLM testing) About the project We are building an AI MVP for a UK government-funded knowledge platform on climate, environment and nature. It has two features: a question-and-answer assistant that gives cited answers from a curated document library, external libraries and the web; and an automated metadata extractor for bulk document uploads, reviewed by a communications team before publishing. Security and accuracy are critical. Give two prompt injection tests you would run against a document Q&A tool. 4. Which tools would you use for this project, and why? 5. Your availability from mid-November and your rate.
