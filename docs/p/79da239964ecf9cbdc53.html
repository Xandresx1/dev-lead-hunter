Full-Stack Development Team Wanted for a Crypto Trading Platform — Website & Mobile Apps I am looking for an experienced developer or development team to build a cryptocurrency trading platform with a website, a mobile-friendly web interface, and dedicated iOS and Android applications. The goal is to create a professional, user-friendly platform with a consistent experience across desktop and mobile devices. I am seeking a development partner who can help with planning, UI/UX design, development, testing, deployment, and post-launch support. Platforms Required Website: A complete desktop web platform for users and a web-based administration panel. Mobile web: A responsive version of the website optimized for smartphone and tablet browsers. Mobile applications: Dedicated iOS and Android apps connected to the same backend as the website. A responsive website alone will not satisfy the mobile application requirement. Please specify whether you propose native apps or a cross-platform framework, and explain your recommendation. Main Features The initial scope should cover the following features, with the final requirements agreed before development: Account registration, login, password recovery, and two-factor authentication. User profiles and an identity verification workflow through an agreed third-party provider. Account dashboards displaying balances, portfolio information, and transaction history. Cryptocurrency deposits and withdrawals for the assets and networks selected during planning. Spot trading with market and limit orders. Live market prices, price charts, an order book, and trading history. Deposit, withdrawal, order, and account notifications. Customer support access from both the website and mobile apps. Administration Panel The web-based admin panel should allow authorized staff to: Manage users, account status, and access permissions. Review verification status and withdrawal requests. Monitor deposits, withdrawals, and trading activity. Configure supported assets, trading pairs, and platform fees. Access operational reports and audit logs. Technical Planning and Security Before development begins, I would like you to propose the architecture and explain: How the website and mobile apps will share backend services and data. Whether trading will use a custom matching engine or an external exchange/liquidity integration. How wallet infrastructure, custody, private keys, and withdrawal approvals will be handled. Which third-party providers, licenses, and subscriptions will be required. How you will approach security testing, backups, monitoring, and maintenance. The initial build should be demonstrated in a test environment, using testnets or simulated funds where applicable. Public launch and real-fund functionality must be separately approved after the agreed security and legal/compliance reviews. Please clearly identify any security audits, legal/compliance work, or third-party services excluded from you
