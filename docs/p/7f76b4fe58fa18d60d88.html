Portal Escorts con Perfiles Privados Quiero lanzar un portal web para escorts donde cada perfil muestre fotos, descripción y datos de contacto, pero estos últimos solo se revelen a los visitantes que se registren. El registro debe ser muy sencillo: correo electrónico y contraseña, con confirmación por e-mail. Alcance principal • Listado de perfiles de escorts con galería fotográfica y sección de contacto. • Sistema de registro e inicio de sesión que valide el correo y oculte/ revele la información de contacto según el estado del usuario. • Panel de administración para que yo pueda crear, editar, activar o desactivar perfiles. • Diseño responsivo y amigable para móviles y escritorio. • Código bien organizado y documentado para facilitar futuras ampliaciones (por ejemplo, filtros de búsqueda o autogestión de perfiles). Entregables - Sitio funcional instalado en mi servidor de pruebas. - Base de datos configurada y archivo de respaldo. - Manual rápido de despliegue y uso del panel. - Acceso a repositorio o paquete completo del código fuente. Preferiría una solución en WordPress, Laravel u otro framework PHP que garantice rendimiento y seguridad, pero estoy abierto a recomendaciones siempre que el resultado cumpla con los puntos anteriores. Presupuesto: 250.0-750.0 EUR Skills: PHP, Website Design, Graphic Design, Web Security, WordPress, MySQL
