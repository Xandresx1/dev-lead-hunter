Plataforma de Turismo y Experiencias Inmersivas Buscamos un desarrollador o equipo de desarrollo de software para diseñar una APP de turismo, con un funcionamiento similar al de Airbnb Experiences. Requerimos una aplicación web responsive, escalable y adaptable a una futura aplicación móvil (iOS y Android), con arquitectura frontend/backend, base de datos y APIs REST o GraphQL. La plataforma debe incluir autenticación y gestión de usuarios (OAuth 2.0), perfiles diferenciados para usuarios y anfitriones, publicación y administración de experiencias con fotografías, descripciones, ubicación, precios y disponibilidad; motor de búsqueda con filtros por categoría, ubicación y fechas; geolocalización y mapas interactivos mediante Google Maps API o Mapbox; sistema de reservas con calendario y disponibilidad en tiempo real; integración de pasarelas de pago mediante APIs como Stripe, Mercado Pago o Wompi; notificaciones automáticas por correo electrónico y push (Firebase Cloud Messaging); sistema de valoraciones y reseñas, favoritos y paneles de administración para gestionar usuarios, experiencias y reservas. Se requiere una interfaz UX/UI intuitiva, visualmente atractiva y optimizada para dispositivos móviles, con infraestructura cloud, almacenamiento seguro de datos, integración de servicios externos y una arquitectura modular que permita incorporar nuevas funcionalidades progresivamente. Buscamos profesionales con experiencia en plataformas tipo marketplace, sistemas de reservas, integraciones API y desarrollo de aplicaciones escalables. Se requiere el desarrollo de un módulo de experiencias digitales inmersivas e interactivas, integrado a la plataforma principal, con capacidad de reproducción y sincronización de contenido multimedia (audio, imágenes, animaciones y recursos interactivos). El sistema deberá contar con infraestructura de almacenamiento en la nube (AWS S3, Google Cloud Storage o Firebase Storage), distribución de contenido mediante CDN y tecnologías de streaming para optimizar la carga y reproducción de archivos. Se contempla la implementación de motores de interacción basados en eventos, secuencias dinámicas y mecánicas de gamificación mediante tecnologías como HTML5, WebGL, Three.js o motores compatibles con entornos web. Adicionalmente, se requiere integración con APIs de respuesta háptica (Vibration API o funcionalidades nativas según compatibilidad del dispositivo), Web Audio API para procesamiento y sincronización de sonido, y sistemas de seguimiento del progreso e interacción del usuario. La arquitectura deberá permitir la administración de contenidos desde un CMS, la ejecución de experiencias interactivas sin instalaciones adicionales y la incorporación progresiva de nuevos módulos, garantizando compatibilidad multidispositivo, rendimiento, escalabilidad y una experiencia fluida.
