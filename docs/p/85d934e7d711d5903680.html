Automatización IA Respuestas Multicanal CRM Quiero construir un sistema que, a partir de nuestros historiales de conversación con clientes, sugiera respuestas inteligentes para los mensajes que ingresan tanto por correo electrónico como por WhatsApp. Flujo deseado • Cuando llega un mensaje, la IA genera una respuesta preliminar usando los chats previos como base de conocimiento. • Esa respuesta se muestra en una página web donde mi equipo puede leerla, editarla si hace falta y aprobarla antes de enviarla. • En horario laboral, la respuesta aprobada se envía automáticamente; fuera de horario no debe responder nada. Integración con WhatsApp • Cada correo entrante debe reenviarse también a nuestro número de WhatsApp para que, si lo preferimos, podamos contestar con un mensaje de voz. • El sistema debe transcribir ese audio y devolverlo al hilo de correo como texto formateado. Seguimiento de oportunidades Si un cliente no responde o la venta no se cierra, la plataforma enviará recordatorios automáticos que incluyen un descuento configurable para incentivar la compra. Requisitos técnicos clave – Canales obligatorios: correo electrónico y WhatsApp. – Motor de IA entrenado en nuestros chats históricos. – Panel web simple y rápido para aprobar cada mensaje. – Restricción de horario configurable. – Registro estilo CRM: conversación, estado, fecha del último recordatorio y resultado. Entregables mínimos 1. Código fuente completo y documentación de instalación. 2. Panel web funcional para vista previa y aprobación. 3. Conectores operativos a Gmail/IMAP y API de WhatsApp Business. 4. Lógica de follow-up con descuentos y control de horario. 5. Guía rápida para que mi equipo pueda ajustar prompts, descuentos y horarios sin depender de desarrollo.
