Desarrollo completo de Cynnk WebApp Busco un desarrollador que construya la primera versión funcional de Cynnk, una aplicación web con dos perfiles claramente diferenciados: postulantes y empresas que desean contratar talento Qué espero lograr La plataforma debe quedar operativa de extremo a extremo. Al ingresar, cada usuario selecciona su tipo de cuenta y accede a funcionalidades específicas: Para estudiantes • Perfil interactivo donde puedan identificar fortalezas, autodiagnosticar competencias y visualizar su posicionamiento frente al mercado. • Sección de aprendizaje con enlaces a cursos externos (por ejemplo, integración con la API de Platzi). • Espacio para aceptar y entregar retos prácticos propuestos por las empresas. Para empresas • Panel corporativo que permita: – Crear y editar vacantes definiendo requisitos, habilidades técnicas y competencias blandas. – Recibir perfiles de estudiantes – Consultar en todo momento el estado de cada candidato (postulado, en evaluación, finalista, etc.). Motor de matching y evaluación El sistema debe analizar los datos de ambas partes y comunicarlas entre si Tecnología sugerida Soy flexible, aunque valoro frameworks modernos (React, Next.js o Vue para el front; Node.js, Django o Laravel para el back). Bases de datos relacionales o NoSQL según convenga. El código debe quedar documentado y versionado en Git. Entregables 1. Repositorio con frontend, backend y scripts de despliegue. 2. Base de datos estructurada con datos de prueba. 3. Manual breve de instalación y uso. 4. Demo desplegada (puede ser en Vercel, Heroku, AWS u otra plataforma gratuita). Criterios de aceptación • Registro e inicio de sesión funcional para ambos perfiles. • Flujo completo de creación de vacante y recomendación de candidatos. • Visualización de portafolio y retos entregados por el estudiante. • Interfaz responsiva y pruebas básicas que aseguren estabilidad. Si tienes experiencia en marketplaces, HR tech o sistemas de matching, será un plus. Espero recibir tu propuesta con stack sugerido y tiempo estimado de entrega.
