AI Software for Restaurant and Cafe owners I need an end-to-end AI platform that lets restaurant, café, and cloud-kitchen owners open a web dashboard, plug in their data, and immediately see what they should prep, purchase, or promote tomorrow. The core goal is clear: predict sales accurately, cut ingredient waste, and lift margins across multiple locations and cuisines worldwide. Here is the workflow I have in mind: • Data ingestion: the system must accept past sales and order history, real-time ingredient stock figures, supplier delivery schedules, plus external signals such as weather forecasts, local holidays, and city-level events. Simple manual CSV uploads are fine for an MVP, but API connectors to common POS, inventory, and weather/event feeds will be needed next. • Forecast engine: use proven machine-learning techniques (Python, TensorFlow/PyTorch, or similar) to generate daily and weekly demand forecasts per menu item and location. Accuracy should improve continuously as more data flows in. • Insight layer: turn those forecasts into actionable recommendations—purchase quantities, prep lists, waste-risk alerts, and profitability projections—surfaced through intuitive charts and alerts. • Web dashboard: a responsive, browser-based interface (React, Vue, or similar front-end; Django, Node, or comparable back-end) with role-based access, multi-store switching, and clear KPI visualizations. No mobile app for now; the entire experience must feel seamless on desktop screens. • Deployment & hand-off: containerised code (Docker/Kubernetes), CI/CD scripts, basic documentation, and a short video walkthrough so I can demo it to pilot clients. Acceptance criteria 1. Given three months of historic data, the model delivers item-level forecasts with ≤15 % MAPE on a blind test week. 2. Dashboard loads in <2 s and updates insights within 60 s of new data uploads. 3. All four data sources—sales, stock, supplier deliveries, and external events—are reflected in the recommendations panel. 4. Code and documentation allow another developer to reproduce results on a fresh cloud instance. If this scope is clear and you have shipped similar AI/ML SaaS products, let’s talk timelines and milestones. Presupuesto: 250.0-750.0 AUD Skills: PHP, Python, Django, Software Architecture, Machine Learning (ML), Node.js
