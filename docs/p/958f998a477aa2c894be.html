Hospital Operations Web App Development I want to replace our scattered spreadsheets and legacy software with one secure, browser-based application that keeps the whole hospital running smoothly. The core focus is on the operational side—assigning staff, managing rooms and beds, tracking hospitalisations, handling prescriptions, and giving management clear oversight of daily activity. Alongside those workflows, the same system must store full patient records: medical history, visit notes, prescriptions, test results, plus all billing and insurance information in one place. Different user groups will see only what they need: doctors and nurses for clinical data entry, reception and billing staff for scheduling and invoicing, and hospital managers or administrators for high-level dashboards and analytics. Key elements I expect: • Intuitive, role-based dashboards (doctors/nurses, reception/billing, managers). • CRUD interfaces for staff rosters, room/bed allocation, prescriptions, and hospitalisation logs. • Patient record modules covering history, notes, lab results, prescriptions, billing, and insurance. • Searchable audit trail for every change. • Secure login (preferably JWT or OAuth2), granular permission matrix, and HIPAA-grade encryption at rest and in transit. • Responsive UI so clinicians can open it on tablets at the bedside. • Clear documentation and a deployment script (Docker or similar) so IT can host the solution on-prem or in the cloud. I’m open on the stack—if you prefer MERN, Django + React, or Laravel + Vue, outline why it fits best, along with database choice (PostgreSQL, MySQL, or MongoDB). Include any relevant libraries for charts, calendar scheduling, or PDF generation for discharge summaries. Deliverables will be: 1. A fully functional web application meeting the specs above. 2. Source code in a private Git repo with commit history. 3. Setup instructions and environment files. 4. A short hand-over session (video call or recorded demo) walking through deployment and key features. Please estimate timeline and milestones, highlight similar hospital or clinic systems you’ve built, and mention any compliance experience you can bring to the project.
