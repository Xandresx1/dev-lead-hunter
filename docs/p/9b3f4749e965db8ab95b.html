End-to-End Azure DevOps Pipeline I need an experienced DevOps engineer to architect and implement a complete CI/CD workflow that takes code from Azure DevOps Repos all the way to a running set of services on Azure Kubernetes Service. Context • The product is a suite of multiple connected services (separate containers, shared networking). • Our target environment is Microsoft Azure, so native services such as AKS, Azure Container Registry, Azure Pipelines, and optional tools like Key Vault and Application Insights should be woven into the solution. • Every code push must automatically trigger build, unit/integration tests, container image creation, vulnerability scanning, and a rolling deployment to the Kubernetes cluster. What I expect you to deliver • A reproducible infrastructure definition (ARM, Bicep, or Terraform) that provisions AKS, ACR, and any supporting resources. • Dockerfiles or multi-stage builds for each service, optimised for size and security. • An Azure Pipelines YAML (or multi-stage classic pipeline if justified) that covers build, test, image publish, and deployment. • Kubernetes manifests or Helm charts, version-controlled alongside the application, enabling blue/green or canary strategies. • Clear README or wiki docs so my in-house team can understand, extend, and troubleshoot the workflow. • A brief hand-off session where you walk me through the setup, from commit to production. Acceptance criteria 1. Commit to main triggers the full pipeline with zero manual steps. 2. All services deploy successfully to AKS using rolling updates without downtime. 3. Pipeline failures clearly surface logs and test reports in Azure DevOps. 4. Everything is codified and versioned in the repo—no click-ops. If you have recent, hands-on experience delivering similar Azure-based pipelines for microservice architectures, I’m looking forward to working with you.
