Automate Zillow Lead Workflow Show case the portfolio. I need our Zillow inquiries to flow seamlessly from first contact through follow-up without anyone copy-pasting a thing. Here’s how I picture the build: • Trigger: Zillow forwarding email (or API if you know a better method). • Automation layer: Zapier, Make, n8n—use whichever you’re strongest in, but document the workflow clearly. • Messaging: Twilio or any SMS tool that lets us personalize the auto-reply, log delivery, and throttle volume. • Data store: Keep using our current Google Sheets workbook; add only the columns or hidden sheets you need for tracking statuses, timestamps, and next-action dates. The lead record appears in the “Leads & Waitlist” tab with no duplicates and all Zillow fields mapped. 3. Any status change in the sheet (e.g., “Contacted”, “Tour Scheduled”) updates the automation so the same lead isn’t re-messaged. 4. The daily “Who to Call” tab or filtered view refreshes automatically and shows no stale leads. 5. A short Loom walkthrough and exported workflow file are provided so I can maintain it. If you’ve ever stitched together Zillow, Sheets, and an SMS gateway before, this should be quick work. Show me one Zapier, Make, or n8n scenario you’re proud of and tell me what you would check first if a rent reminder ever went out with the wrong amount.
