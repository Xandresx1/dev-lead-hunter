Motor de Recomendación para App de Películas Buscamos a un desarrollador o equipo para construir el motor de recomendación de una app móvil de películas y una interfaz básica para probarlo con usuarios. Ya tenemos el diseño de referencia: necesitamos a alguien que lo implemente, no que lo diseñe. 1. Algoritmo de recomendación (parte principal) Perfil de gusto por usuario. Se construye con señales explícitas («me interesa», «para otro momento», «ya la vi») y señales diferidas (feedback días después de ver una película). Recomendación por contenido. Usa embeddings semánticos de sinopsis y metadatos (tono, ritmo, estructura narrativa), no solo género, con búsqueda por similitud vectorial. Filtros combinables. Estado de ánimo (mood), género, director, época y duración. Explicabilidad. Cada recomendación devuelve un porcentaje de afinidad y una razón breve. Exclusiones. No vuelve a proponer lo ya visto ni lo descartado. Disponibilidad. Consulta en qué plataformas está la película en Colombia, mediante una API de catálogo (TMDB, JustWatch o Watchmode). 2. Backend API REST documentada con autenticación básica (correo, Google o Apple). Base de datos con soporte vectorial (por ejemplo PostgreSQL con pgvector). Registro de eventos de uso para medir y ajustar el algoritmo. 3. Interfaz básica (móvil o web responsive) Onboarding corto: elegir moods y algunas películas de arranque. Pantalla de recomendación con película, afinidad y razón. Acciones con gestos (deslizar) y botones de respaldo. Filtros y perfil con historial de películas vistas. No necesita pulido visual avanzado, pero sí funcionar de punta a punta con datos reales. Fuera de alcance: pagos, publicidad, funciones sociales, notificaciones push y publicación en tiendas de apps. Entregables Código en repositorio Git, con README e instrucciones de despliegue. API documentada (Swagger u OpenAPI). Documento breve que explique cómo funciona el algoritmo y cómo ajustarlo. Evaluación básica del algoritmo (métricas sobre un set de prueba). Despliegue en un entorno de pruebas. Stack: abierto. Proponer lo que dominen. Lo ideal es Python o Node en el backend y React Native, Flutter o web en el front. Habilidades deseadas: sistemas de recomendación, embeddings y NLP, bases de datos vectoriales, desarrollo de APIs y desarrollo móvil o web. Qué pedimos en su propuesta Precio total, con desglose entre algoritmo, backend e interfaz. Tiempo estimado e hitos. Stack propuesto. Proyectos similares. Preguntas o riesgos que vean en el alcance. Presupuesto: 3000.0-5000.0 USD Skills: Python, Graphic Design, Logo Design, Photoshop, Android, Machine Learning (ML)
