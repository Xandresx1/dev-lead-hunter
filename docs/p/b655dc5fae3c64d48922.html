GPU Shuffleboard Arcade Game Mode (Python) I already have an overhead scoring system for Shuffleboard table running on a Raspberry Pi 5 (8 GB RAM) that tracks every puck in real time. What I am missing is a fresh arcade-style game mode that runs almost entirely on the GPU so the CPU can stay focused on camera vision and tracking. FAQ section below. Here is what I need you to build: • A two-team competitive game concept (think Red vs Blue, one or two people per side) that feels fast, fun and easy to learn. e.g. Coin Hoarder mode where virtual coins are placed on a representation of the table and teams try to collect them by sliding pucks into them. There are 4 pucks per team (4 red and 4 blue pucks). • All game logic written in Python, driven by the live array of puck coordinates I will be streamed to your game mode. • A visual layer rendered by the GPU. My early tests point to raylib through pyray as the cleanest solution, but I am open to any Python-friendly framework that can prove equal or better performance on the Pi 5. • Dual-screen support. The primary vertical screen carries the full animated game; the second back-to-back screen can simply mirror it or fall back to a lightweight screensaver when nothing important is happening. • Consistent fps (at least 24fps) on the Pi with minimal CPU load. • A single importable module (plus assets) that I can drop into my existing repo, documented well enough for me to tweak game parameters later. Acceptance criteria 1. Game runs on a clean Pi OS image with nothing but the default drivers and whichever library you choose. 2. GPU usage is clearly heavier than CPU during play (I will profile). 3. No big frame drops at 1080×1920 per screen. 4. Puck coordinate injection via a simple function call instantly updates the visuals and logic. 5. Clean hand-off: code, asset folder, brief setup guide, and a video capture showing the mode in action. FAQ: 1- both screens are driven by the same Pi5 through the 2 HDMI ports. 2- live puck coordinates are already in table-relative cm or px space. Format: stdout or TSV stream. Line format t<float>\tid<int>\tcolour<str>\tx<int>\ty<int>, tab-separated, no header. e.g. t=12345.678 id=0 colour=red x= 1024 y= 512 t=12345.678 id=1 colour=blue x= 1800 y= 900 or 12345.678000 0 red 1024 512 12345.678000 1 blue 1800 900 If this sounds like your kind of project, let’s talk about the game and make it happen. I am aiming at around 250$ budget, but I am open to negotiation. Presupuesto: 30.0-250.0 USD Skills: Python, Game Design, Animation, Game Development, Raspberry Pi
