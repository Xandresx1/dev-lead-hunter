📢 BUSCO DESARROLLADOR DE CATÁLOGO DIGITAL CON INVENTARIO Para mi negocio Mujer Bonita Boutique 💗 Busco una persona con experiencia en sistemas de inventario para crear un catálogo digital funcional para dos sucursales. Requisitos del proyecto: ✔️ Dos catálogos independientes, uno por sucursal. ✔️ Más de 600 productos, con posibilidad de agregar más de 1,000 piezas únicas. ✔️ Cada producto debe mostrar fotografía, precio y talla. ✔️ Buscador por talla, color y modelo. ✔️ Actualización automática: al vender una pieza, debe dejar de aparecer como disponible. ✔️ El personal de tienda podrá registrar ventas, pero no modificar precios. ✔️ Yo, como dueña, podré agregar, editar y quitar fotografías y productos. ✔️ Catálogo accesible mediante un enlace para compartir por WhatsApp y Facebook. ✔️ Capacitación para aprender a utilizar el sistema. ✔️ Posibilidad de comenzar con las fotografías que ya tenemos y agregar las faltantes posteriormente. Busco una solución práctica, fácil de manejar desde el celular y que permita mantener actualizado el inventario de ambas sucursales. 📩 Personas interesadas: enviar mensaje privado con ejemplos de trabajos similares, precio total, tiempo de entrega Número 919 121 9586 Por favor, indicar si desarrollan el sistema completo o si ofrecen únicamente diseño de catálogo. ¡Gracias! 🌸
