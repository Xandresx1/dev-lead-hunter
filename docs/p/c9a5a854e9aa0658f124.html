Interactive Coding Game Platform I’m building a browser-based platform that turns learning to code into a playable game. The core idea is simple: users write real JavaScript (and eventually other languages) inside an embedded editor, run it instantly, and watch the results unfold as characters move, puzzles unlock, or levels progress. Everything must happen in one seamless, visually engaging screen so beginners stay focused on solving challenges rather than juggling tools. Scope of work • Front-end game interface – a lightweight, responsive canvas/WebGL scene or similar where code-driven actions are rendered in real time. • In-browser code editor – syntax highlighting, autocompletion, basic linting, and a “run” button that pipes the code straight into the game engine without page reloads. • Challenge engine – JSON or database-driven levels that define starting state, goal conditions, and test cases so I can add new puzzles without touching core logic. • Progress & scoring – store user attempts, completion status, and simple leaderboards so learners see their improvement. • Modular back end (Node/Express or comparable stack) – REST endpoints for authentication, challenge retrieval, and result submission. Acceptance criteria 1. A user can open the site, sign up, complete at least three tutorial levels, and see a success screen without manual intervention. 2. Incorrect code returns helpful console or overlay feedback in under two seconds. 3. Page loads and runs smoothly on any modern desktop or laptop browser (Chrome, Firefox, Edge, Safari). 4. All source code is provided with clear setup instructions and comments. If this first milestone performs well I’ll extend the roadmap to additional languages, multiplayer challenges, and mobile-specific layouts, so clean, extensible architecture is important from day one. Presupuesto: 250.0-750.0 USD Skills: PHP, JavaScript, Mobile App Development, HTML5, HTML, Node.js
