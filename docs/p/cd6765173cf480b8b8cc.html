Agentes IA para Automatización Interna Busco desarrollar varios agentes de inteligencia artificial que se encarguen de automatizar procesos internos de forma fiable y segura. Objetivo principal Crear agentes capaces de: • Gestionar correos, documentos y solicitudes entrantes. • Actualizar datos y generar reportes periódicos. • Coordinar tareas, recordatorios y seguimiento entre miembros del equipo. Entorno y herramientas existentes Mi equipo trabaja con Google Workspace (Gmail y Documentos), Microsoft Outlook, Excel y Teams, además de un sistema propio de gestión de clientes. El proyecto debe integrarse con estas plataformas mediante sus API oficiales o conectores ya disponibles, de modo que los usuarios sigan trabajando dentro de los canales habituales. Alcance esperado 1. Análisis de flujos actuales y mapeo de puntos de automatización. 2. Diseño y desarrollo de los agentes de IA, incluyendo lógica de conversación, acceso a datos y reglas de negocio. 3. Integración con Google Workspace, Microsoft 365 y nuestro sistema interno. 4. Pruebas de funcionamiento y ajustes iterativos. 5. Documentación clara de instalación, uso y mantenimiento, junto con un breve taller de traspaso de conocimiento. Requisitos técnicos deseados – Experiencia con herramientas de IA conversacional (por ejemplo, OpenAI, LangChain o DialogueFlow). – Conocimientos de OAuth y autenticación para Google y Microsoft APIs. – Buenas prácticas de seguridad y manejo de datos sensibles. Entregables • Código fuente bien documentado. • Agentes desplegados en entorno de prueba totalmente operativos. • Manual de usuario y guía técnica. Si tienes experiencia creando este tipo de soluciones y puedes demostrar integraciones similares, estaré encantado de revisar tu propuesta y plazos estimados.
