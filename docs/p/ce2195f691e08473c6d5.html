Proximity Sensor Kiosk Activation Solution Proximity Sensor – Countertop Kiosk Specification 1. Overview Farmers Hub wishes to install a customer proximity sensor on a countertop promotional kiosk located on top of refrigerated display units in BP service stations. The kiosk displays promotional messages and videos highlighting the day's fresh, direct-from-farm produce. Its purpose is to attract customers' attention while they are waiting in the queue to pay. The proximity sensor will automatically activate the kiosk when a customer approaches, ensuring promotional content and audio are only active when customers are nearby. 2. Functional Requirements The proximity sensor should provide the following functionality: A. Customer Detection • Detect customers approaching the kiosk from approximately 5 metres away. • Detection distance should ideally be configurable to suit different store layouts. • The sensor should reliably detect customers approaching from the front of the kiosk. B. Automatic Activation When a customer is detected, the sensor should: • Wake the kiosk from hibernation or sleep mode, if applicable. • Activate the kiosk's audio and set the volume to a predefined level. • Start or resume promotional content playback. C. Activation Duration • The activation period should be configurable by Farmers Hub (e.g. 2–5 minutes). • If no further customers are detected during this period, the kiosk should automatically return to its previous standby state. • If another customer is detected while the kiosk is active, the activation timer should reset, keeping the kiosk active for the configured period from the latest detection. D. Audio Control • When no customers are detected, the kiosk volume should be set to zero or muted. • When a customer is detected, the volume should automatically return to a predefined, configurable level. • Volume settings should be adjustable remotely or through the kiosk configuration. 3. Customer Detection Data and Reporting A preferred additional feature is the ability to record every new customer detection event. This data will help Farmers Hub understand customer traffic patterns, identify peak periods and compare customer engagement with produce sales.
