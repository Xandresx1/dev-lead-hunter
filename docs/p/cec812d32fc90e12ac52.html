Automated Translation Marketplace Platform I need a full-featured web platform that brings clients and translators together in one place. The core flow is simple: a client uploads a document or certificate, the system instantly suggests the most suitable translators, and the client picks the one they prefer from that shortlist. From there, everything—file exchange, messaging, deadline tracking, delivery and payment—happens inside the site. Key capabilities I want to see: • Secure account areas for both clients and translators, with profile pages that highlight language pairs, certification, turnaround times and ratings. • An automated matching engine that reads the source/target languages plus any specialist field tags, then surfaces a short list of translators ready to take the job. • A clean client dashboard to create requests, upload files (PDF, DOCX, image scans), accept a quote, and monitor progress in real time. • A translator workspace for accepting or declining offers, messaging the client, delivering the final file, and issuing an invoice. • Integrated payment processing that releases funds on client approval, with an admin override for dispute resolution. • Admin panel for user management, job oversight, fee settings, promo codes, analytics and basic CMS updates. • GDPR-compliant data handling and SSL-secured file storage. Accepted deliverable: a responsive, production-ready site (React, Vue, or similar front end; Node, Django, Laravel or comparable back end; MySQL/PostgreSQL) deployed on a cloud host of your choice, with source code in a Git repo and step-by-step setup documentation. I’ll review against the working demo, code quality, automated translator suggestions, and the end-to-end job cycle for a sample document before sign-off.
