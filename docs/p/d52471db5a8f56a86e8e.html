PowerApps Data Capture to Lakehouse I want a straightforward Power Apps canvas app that lets our team enter monthly sales-pipeline and order-book figures, press Save, and have every new submission land directly in a Microsoft Fabric Lakehouse table. Deliverables 1. A Power Apps .msapp file (or an exported solution) containing the finished canvas app. 2. Connection setup instructions and any Power Automate or custom connector code used to push data to the Lakehouse table. 3. A short README covering the table schema you used, the security roles required, and steps to deploy the package in another tenant. Acceptance criteria: new entries appear in the correct Fabric Lakehouse table within seconds of submission, records cannot be edited or deleted through the app UI, and the solution installs without premium-license dependencies.
