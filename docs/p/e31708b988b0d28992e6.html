POS & Hikvision Video Integration I want my point-of-sale data and Hikvision camera footage to speak to each other. Each completed sale should instantly pull up the exact camera angle that captured the transaction and save that pairing for later review. When a refund, void, or discount is entered, the system must flag it in real time—an on-screen pop-up, email, or another prompt is fine as long as it links me straight to the relevant clip. Beyond live alerts, I also need a searchable history. I’d like to key in a receipt number, date range, product, or employee name and get a list of matching sales with time-stamped thumbnails and one-click playback. Exportable reports (CSV or PDF) that preserve the video links will make audits simpler. My store already runs on Hikvision cameras and an NVR that exposes ISAPI / ONVIF and RTSP streams. The POS platform has an open API and webhook support; I’m happy to share docs once we start. Whether you build a small Windows service, a web dashboard, or a hybrid approach, I just need something reliable that I can install locally and manage without deep technical know-how. Deliverables • Transaction-to-video sync module with live overlay • Alert engine for refunds, voids, and discounts • Searchable reporting interface with export options • Install script, source code, and brief user guide Acceptance criteria • Video launches within two seconds of selecting a sale • Alerts fire no later than five seconds after the triggering POS event • Searches return relevant results in under three seconds If you’ve integrated POS data with Hikvision (or other ONVIF systems) before, that’s a big plus. Let’s talk through your proposed tech stack, timeline, and any questions you have.
