AI Order Processing Automation I need an AI-driven agent that sits inside our workflow and, the moment a new order appears in our marketplace-based order-management system, takes care of everything that follows. The agent should read the order payload, generate a correct invoice inside our accounting tool, create the corresponding shipping task or label through the shipping API we already use, and then push a friendly status update back to the customer via the marketplace’s messaging channel or email. The build can be in Python (FastAPI, async) or Node, but it has to be clean, test-covered code that leverages an LLM such as GPT-4 for the conversational pieces. You will connect to the marketplace API, our invoicing endpoint, and ShipStation (or a comparable service) using secure token handling, and you’ll maintain a lightweight Postgres record of every action for traceability. Please include: • A Docker-ready service or AWS Lambda handler that can be triggered by a webhook when a new order arrives • Environment-variable driven configuration for all credentials • Unit tests plus a short README explaining local setup, deployment, and how to extend the agent’s skills The project is complete when I can watch a new marketplace order flow all the way to “shipped” status with an invoice generated and the buyer automatically informed—no manual keystrokes required.
