AI Meeting Insights and Action Tracker -- 2 AI Developer Needed for Meeting Insights and Action Tracker Project Overview We are looking for an experienced AI developer to build an AI-powered meeting analysis tool that can transform meeting transcripts into structured summaries, key decisions, and actionable tasks. The objective is to help teams organize meeting outcomes, identify important responsibilities, and reduce the time spent preparing meeting reports manually. Project Requirements The application should allow users to upload meeting transcripts in TXT, DOCX, or PDF format. Once uploaded, the system should use an AI model to analyze the content and generate a concise, well-organized meeting summary covering the main discussion points, important updates, and key outcomes. The system should also identify decisions made during the meeting and extract actionable tasks from the discussion. Each task should include the assigned person's name and deadline where these details are mentioned in the transcript. It should also highlight unanswered questions, unresolved issues, and pending matters that may require further attention. The generated results should be presented in a simple interface where users can review and edit the summaries, decisions, and action items before finalizing the report. Users should also be able to export the completed meeting report into a downloadable Word or PDF document. Technical Requirements The solution should be developed using Python and an appropriate AI/LLM API, such as OpenAI. Experience with Natural Language Processing, document processing, API integration, and basic frontend development will be beneficial. Deliverables The final deliverable should include a functional AI meeting analysis application, transcript processing functionality, automated summary and action-item extraction, an editable results interface, downloadable meeting reports, basic testing, and setup documentation. Timeline: Please provide your estimated delivery time based on the proposed solution. Please share examples of similar AI-powered applications or automation solutions you have previously developed.
